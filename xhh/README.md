# 小黑盒 · IM 三合一伪装外观（xhh-im.user.js）

一套油猴脚本，将 [xiaoheihe.cn](https://xiaoheihe.cn/) 网页版深度伪装成 **钉钉 PC 端**、**飞书 IM** 或 **企业微信** 办公聊天界面。

**只换皮，不碰隐私与凭证**：帖子自动投影为聊天消息气泡，点赞、收藏、关注、评论全部点击官方原生控件触发（接口签名与风控交给站点自身 runtime），免逆向、免签名、零风控风险。

---

## 核心功能

### 1. 三合一风格秒切（钉钉 / 飞书 / 企业微信）
* 一套脚本集成三款主流办公协同界面，随时一键切换，偏好自动本地记忆；
* 官方风格图标与调色板，自动跟随系统深浅色模式。
* **左侧导航栏复刻 linux.do IM 版**：钉钉默认 56px 窄条（纯图标），点「展开」切成带文字的宽条；飞书 / 企业微信点「收起」压成 68px 大图标 + 小字；团队图标与名称都可点击自定义（1~2 字 / emoji / 图片 URL）。

### 2. 弹出式全局搜索（⌘ / Ctrl + K）
* 飞书同款居中搜索面板：类型筛选（全部 / 帖子 / 用户 / 话题）、结果分组、关键词高亮、复制链接、最近搜索；
* **搜索历史可管理**：每条最近搜索右侧的 `×` 单独删除，分组标题右侧「清空」一键清空全部记录（偏好写入 localStorage）；
* 数据来源是脚本被动缓存的官方接口结果（信息流 / 搜索接口），本地没有命中时回车直接转到站内搜索，由中栏渲染完整搜索结果；
* 侧栏与列表里的搜索框都变成「点一下弹出搜索」，Enter / ↑↓ / Esc 全键盘操作。

### 3. 帖子流式聊天化阅读
* 信息流（社区首页、话题、搜索结果、我的收藏、浏览历史）自动排版为日常聊天气泡，清晰展示作者、等级、发布时间、标题与配图；
* 触底自动加载下一批帖子，右上角刷新或再次点击「社区首页」即可换一批；
* 侧边栏常驻假会话填充，融入办公环境不穿帮。

### 4. 右侧详情抽屉与多级评论区
* 点击帖子从中栏右侧平滑抽出详情抽屉，展示完整帖子正文、图组与多级评论树；
* 阅读详情时主列表阅读进度完全冻结，关闭抽屉即可回到原本阅读进度，不跳路由、不白屏。

### 5. 低质内容过滤（水贴折叠）与关键词高亮
* **低质内容过滤**：短内容漏斗 + 关键词漏斗（全文匹配 / 包含匹配），命中的帖子与评论折叠成一行「简短回复已折叠 @作者: 预览 [展开]」，点开即原地还原；阈值、短词表、屏蔽词表都可在弹窗里配置，可一键恢复默认；
* **关键词高亮**：自定义关注词库，命中词在中栏气泡里常驻黄色高亮，配置保存后立即重涂。

### 6. 摸鱼护栏与防社死机制
* **纯文本摸鱼模式**：一键隐藏所有图片与视频；
* **防窥脱敏模式**：一键将作者头像打散为百家姓单字头像，标题与群名伪装为日常工作项目沟通组；
* **标签页伪装**：Favicon 与浏览器标题自动锁定为对应办公软件（如 `企业微信`、`钉钉 - 工作台`、`飞书`）。

### 7. 完整社交互动
* 聊天气泡与详情抽屉下方快捷栏一键点赞、收藏；
* 支持关注/取消关注作者（改由原生详情页顶部的关注按钮代理执行）；
* 支持在详情抽屉底部直接评论，走原生 ProseMirror 编辑器发送；
* 点击作者头像或昵称可查看其个人主页名片与公开帖子。

## 安装使用

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）或 Violentmonkey 扩展；
2. 打开当前目录下的 [`xhh-im.user.js`](./xhh-im.user.js)，点击 **Raw** 进行安装；
3. 访问 <https://xiaoheihe.cn/app/bbs/home> 即可自动生效（初次安装后请硬刷新一次页面 `Ctrl+F5` 或 `Cmd+Shift+R`）。

> 小黑盒的帖子详情与评论区需要登录后才能由站点自身接口取回：未登录时中栏仍可读公开信息流，详情抽屉会提示加载失败，登录后自动恢复。
> 脚本自身不发起任何带签名的接口请求，也不改写任何凭证，全部数据来自页面已经渲染/已经请求的内容。

## 本地开发与构建

本子模块为**完全独立自包含的 Vite 工程**，与上游其它站点完全解耦：

```bash
cd xhh

# 安装依赖
pnpm install

# 实时监听开发（改动即编译）
pnpm dev

# 代码检查与生产打包（产物自动输出至 xhh-im.user.js 及 dist/xhh-im.user.js）
pnpm lint
pnpm build
```
